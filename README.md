# Python Number Guessing Game

This repository contains a simple **Number Guessing Game** built using Python.

The project was created to practice and apply Python programming concepts learned so far through a small interactive project.

## About the Project

In this game, the program generates a random number and the player tries to guess the correct number.

After each guess, the program provides feedback to help the player determine whether the guessed number is higher or lower than the target number.

The game continues until the player guesses the correct number.

## Concepts Used

- Variables
- Data types
- User input
- `if`, `elif`, and `else`
- `while` loop
- `break`
- Functions
- `random` module
- Comparison operators
- Basic problem-solving

## How to Run

Make sure Python is installed on your system.

Run the Python program using:

```bash
python guessing_game.py
```

Then follow the instructions displayed in the terminal.
